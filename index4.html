How to Use This Site Effectively

1. Write clear titles

Name snippets by what they do ("Debounce function"), not by what they are ("JS code 3"). Future you will find them much faster.

2. Keep language names consistent

Always type the language the same way (e.g. "JavaScript", not "js" or "Javascript"). The language filter and the "Different Languages" counter treat different spellings as different languages.

3. Favorite what you reuse

Press ☆ Favorite on snippets you use often. They appear in Saved CodeBlocks, where you can also edit them as your code improves.

4. Keep one snippet focused

Store one idea per snippet. Small, focused snippets are easier to copy and reuse than long files.

5. Use the filter and the Copy button

On the DashBoard, filter by language, then press Copy to put the code on your clipboard without selecting it manually.

6. Back up regularly

Your snippets live in this browser only. Clearing browser data or switching devices will lose them, so use Export backup every now and then. You can restore with Import backup.
